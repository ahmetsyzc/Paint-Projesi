# 🎨 Paint Projesi

Paint Projesi, C# Windows Forms kullanılarak geliştirilmiş basit bir masaüstü çizim uygulamasıdır.

Proje; Windows Forms üzerinde çizim işlemlerini gerçekleştirmek, `System.Drawing` yapısını kullanmak, fare olaylarını yönetmek ve Bitmap/Graphics işlemleri üzerinde pratik yapmak amacıyla geliştirilmiştir.

## 🚀 Özellikler

- Serbest kalem ile çizim
- Kalem rengi seçme
- Kalem kalınlığı seçme
- Silgi kullanımı
- Silgi kalınlığı seçme
- Dikdörtgen çizme
- Elips/daire çizme
- Düz çizgi çizme
- Çizim alanını temizleme
- Arka plan rengini değiştirme
- Bilgisayardan arka plan resmi yükleme
- Çizimi PNG veya JPG olarak kaydetme
- Çizim sırasında şekillerin önizlemesini görüntüleme

## 🛠️ Kullanılan Teknolojiler

- C#
- .NET
- Windows Forms
- System.Drawing
- Bitmap & Graphics

## 🖌️ Çizim Araçları

Uygulamada farklı çizim işlemleri için kalem, silgi, dikdörtgen, elips ve çizgi araçları bulunmaktadır.

Kalem ve silgi kalınlıkları kullanıcı tarafından değiştirilebilir. Kalem rengi `ColorDialog` üzerinden seçilebilir.

## 🖼️ Arka Plan ve Görsel İşlemleri

Kullanıcı çizim alanının arka plan rengini değiştirebilir veya bilgisayarından JPG, JPEG, PNG ve BMP formatlarında bir görsel yükleyebilir.

Oluşturulan çizim, arka plan ile birlikte PNG veya JPG formatında bilgisayara kaydedilebilir.

## 🎯 Projenin Amacı

Bu proje ile;

- Windows Forms fare olaylarının kullanımı
- Graphics sınıfı ile çizim işlemleri
- Bitmap üzerinde çizim saklama
- Renk ve kalınlık yönetimi
- Dosya açma ve kaydetme işlemleri
- Basit bir çizim uygulamasının çalışma mantığı

konularında pratik yapılmıştır.
